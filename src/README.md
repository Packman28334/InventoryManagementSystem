# Inventory Management System
This is a reference implementation of an inventory management system, as described in FRC team 9562's programming lesson.

## Specifications/Requirements
- Built using Java with proper use of object-oriented programming
  -[x] Items are declared as a class with appropriate getter and setter functions
  -[x] All development is done on a separate branch and merged into `master` by a team lead after a review
  -[x] The Conventional Commits specification is followed for commit names
  -[x] All code is formatted according to the Royal Robotics Code Style Guide
    -[x] Variables, classes, and files are named in appropriate case with descriptive titles
    -[x] Indentation is consistent
- Items possess the following properties:
  -[x] Name
  -[x] Description
  -[x] Quantity/Stock
  -[x] Price
- The user is able to:
  -[x] Add an item to the system
  -[x] Edit the stock and price of each object
  -[x] Delete any item from the system
  -[x] Display all items upon request

Note that the branch is not named appropriately for multi-person development. This is fine for working on solo projects, but when working on a team repository all of  your branches must be prefixed with your initials and include a descriptive name (eg. `GP-InventoryManagement`).
